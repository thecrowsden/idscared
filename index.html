Hello!

Welcome to the IMSCARED ID Maker! If you're not sure what this is for, you probably don't need it.

This unofficial tool allows you to customize your VIP Badge or Worker Card from the IMSCARED post‑game, for use in Remnants of a Scare. By customizing your ID, you can see your own personalized ID in‑game! However, this has a few limitations and quirks, so this ID Maker is designed to make the process as easy as possible, and ensure that your custom ID appears correctly.

"ID" refers to your VIP Badge or Worker Card.


To use the ID Maker, simply select your ID file using the file selector on the main page (or drag the ID file onto it). If you have previously modified your ID, you will be provided with a new blank ID for customization. If you have renamed your ID, it will not be recognized, so it is best to use the original ID file located in your "imscared" Desktop folder.

Once you have finished customizing your ID, download your new ID with the Download button, delete (or move/rename) your original ID, and then place your new ID in the "imscared" Desktop folder. If you rename the new ID, it will not appear in‑game, so ensure that the file name for the ID is correct.


There are some limitations to the ID Maker to ensure that your custom ID appears correctly in‑game. If you wish to further customize your ID, useful documentation is available below. You can download all of the reference images below by clicking the Download link at the bottom of this page.



Note: IDs are intended to be 128x128 pixel images. Scaling the ID to other resolutions will cause unintended issues with how it appears in‑game.



Not everything on your ID appears in Remnants of a Scare. Instead, the game takes the icon and Name/Info portions of your custom ID and applies them on top of a default blank ID. The above images showcase the exact portions of each ID that appear in‑game. Content in the white regions appears in‑game, while content in the black regions does not. The first image is for VIP Badges, and the second image is for Worker Cards.



Any pixels that are the same color as the bottom left pixel will not appear. Instead, they will be replaced with the equivalent pixels on a default blank ID. For VIP Badges, the original color here is solid black (#000000), and for Worker Cards, it is solid white (#FFFFFF). This means that any solid black/white pixels will not appear correctly in game, unless you change the color of the bottom left pixel. For reference, the white pixel in the image above is the pixel that is checked. Any transparent pixels will also be replaced with the equivalent pixels on a default blank ID.



The above images are the shine patterns of the IDs. The white pixels on these images represent which pixels on the original IDs are replaced with their corresponding shine colors. This is not important for functionality, but helps ensure that your ID matches the default blank IDs. The first image is for VIP Badges, and the second image is for Worker Cards.



This is the font used for the IDs. It is the font 8 Bit Wonder at 8px scale, with Antialiasing disabled. It is specifically capitalized letters, as lowercase letters appear slightly differently. The square shape is the "#" symbol.



This is the font used for the "VIP PASS" text on VIP Badges. It is the font 8 Bit Wonder at 12px scale, with Antialiasing disabled. The same information as above applies to this as well, as the only difference is the font size.



These are special characters that do not appear in the actual font. Both of these appear exclusively in the "NAME:" text on Worker Cards. On the left is the letter "E", which is notably one pixel thinner than a normal E. On the right is the colon. The spacing around these characters may not be fully accurate. In the ID Maker, the E can be typed with "=" while the colon can be typed with ":". In addition, a single pixel space can be typed with "|" to adjust the spacing when using these characters. Using these, the "NAME:" text as it appears on Worker Cards can be typed with "NAM=|:".
